# تابورا (Tabora)

پنل پروکسی امن و چندکاربره که کاملاً روی Cloudflare Workers اجرا می‌شود.

تابورا پروتکل‌های **VLESS** و **Trojan** را روی WebSocket ارائه می‌دهد، به همراه یک
داشبورد مدرن دوزبانه (فارسی / English)، محدودیت ترافیک و تاریخ انقضا برای هر کاربر،
و خروجی اشتراک برای کلاینت‌های Xray، Sing-box و Clash/Mihomo — همه از یک فایل
`worker.js` بدون نیاز به هیچ سروری.

> 🌐 [English README](./README.md)

</div>

```
┌──────────────┐   WebSocket    ┌─────────────────┐   TCP    ┌──────────┐
│    کلاینت     │ ─────────────► │ تابورا (Worker) │ ───────► │   مقصد   │
│ v2rayN/Clash │   VLESS/Trojan │  + دیتابیس D1   │          │          │
└──────────────┘                └─────────────────┘          └──────────┘
```

## ✨ ویژگی‌ها

- **دو پروتکل** — VLESS و Trojan روی WebSocket با پشتیبانی از early data (0-RTT).
- **چندکاربره** — UUID اختصاصی، سهمیه ترافیک، محدودیت روزانه و تاریخ انقضا برای هر
  مشترک. کاربران پس از عبور از محدودیت به‌صورت خودکار غیرفعال می‌شوند.
- **چهار فرمت اشتراک** — لیست URI با base64، URI ساده، Clash/Mihomo (YAML) و
  Sing-box (JSON). فرمت به‌صورت خودکار از روی User-Agent کلاینت تشخیص داده می‌شود.
- **داشبورد دوزبانه** — فارسی و انگلیسی با پشتیبانی کامل RTL، تم تیره و روشن، و
  طراحی واکنش‌گرا که روی موبایل هم درست کار می‌کند.
- **صفحه استتار** — هر درخواستی خارج از مسیر مخفی، یک سایت واقعی را آینه می‌کند تا
  اسکنرها و بازدیدکنندگان اتفاقی هرگز متوجه وجود پنل نشوند.
- **کنترل از تلگرام** — بعد از نصب یا بروزرسانی از ربات، کاربرها، ترافیک و کلید قطع
  را از چت مدیریت کنید. داشبورد نشان می‌دهد پنل به تلگرام وصل است.
- **ProxyIP و NAT64** — در صورت مسدود بودن خروجی کلودفلر، اتصال به‌صورت خودکار از
  مسیر رله دوباره تلاش می‌شود.
- **DoH خصوصی** — درخواست‌های UDP DNS از طریق DoH دلخواه شما تونل می‌شوند.
- **نشست JWT** — کوکی HttpOnly و Secure با SameSite=Strict و کلید امضای چرخشی؛
  تغییر رمز عبور تمام نشست‌های فعال را باطل می‌کند.
- **پشتیبان‌گیری و بازیابی** — خروجی کامل تنظیمات به‌صورت JSON و بازگردانی در یک
  استقرار دیگر.
- **گزارش فعالیت** — ورودها، تلاش‌های ناموفق و تمام تغییرات پیکربندی.
- **اسکن آی‌پی تمیز** — راه آی‌پی ثابت واقعی. اسکن چندموجی از مرورگر شما روی آی‌پی‌هایی که واقعاً جلوی ورکر می‌ایستند: برنده‌های قبلی، لبه‌های تاییدشده، کاتالوگ، همسایه‌های /۲۴ و نمونهٔ گسترده‌تر. وقتی نتیجه زیاد است، خودتان انتخاب می‌کنید چند تا ثابت شود؛ هر آی‌پی سالم دقیقاً یک کانفیگ می‌شود.

## 📋 پیش‌نیازها

- یک حساب Cloudflare (پلن رایگان کافی است)
- یک دیتابیس **D1** (توصیه‌شده) یا فضای نام **KV**
- نسخه ۱۸ یا بالاتر Node.js برای بیلد

## 🚀 شروع سریع

### گام ۱ — ساخت دیتابیس

</div>

```bash
npx wrangler d1 create tabora-db
```

<div dir="rtl">

مقدار `database_id` که برگردانده می‌شود را در فایل `wrangler.toml` قرار دهید.

### گام ۲ — پیکربندی

بخش `[vars]` را در `wrangler.toml` ویرایش کنید:

</div>

```toml
ADMIN_PASSWORD = "یک-رمز-قوی-انتخاب-کنید"
SECURE_PATH    = "یک-مسیر-غیرقابل-حدس"
FALLBACK       = "https://www.wikipedia.org"
```

<div dir="rtl">

بهتر است رمز را اصلاً داخل فایل نگذارید:

</div>

```bash
npx wrangler secret put ADMIN_PASSWORD
```

<div dir="rtl">

### گام ۳ — بیلد و استقرار

</div>

```bash
npm install
npm run build
npx wrangler deploy
```

<div dir="rtl">

### گام ۴ — ورود

آدرس زیر را باز کنید:

`https://<نام-ورکر-شما>.workers.dev/<SECURE_PATH>/panel`

هر مسیر دیگری صفحه استتار را نمایش می‌دهد.

> ⚠️ بلافاصله پس از اولین ورود، رمز پیش‌فرض را عوض کنید. داشبورد تا زمانی که این
> کار را انجام ندهید هشدار می‌دهد.

## ⚙️ متغیرهای پیکربندی

همه متغیرها اختیاری هستند به‌جز `ADMIN_PASSWORD`.

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `ADMIN_PASSWORD` | `admin` | رمز پنل. **حتماً تغییرش دهید.** |
| `SECURE_PATH` | `tabora` | مسیر مخفی پنل و اشتراک |
| `UUID` | خودکار | UUID ثابت برای VLESS (نسخه ۴). اگر خالی باشد از رمز ساخته می‌شود. |
| `TROJAN_PASSWORD` | خودکار | رمز Trojan. اگر خالی باشد از رمز پنل ساخته می‌شود. |
| `FALLBACK` | ویکی‌پدیا | سایتی که برای درخواست‌های غیرمجاز آینه می‌شود |
| `PROXY_IP` | — | رله‌ها با کاما جدا می‌شوند، مثلاً `1.2.3.4:443` |
| `BOT_KEY` | خالی | سکرت مشترک لانچر تلگرام برای کنترل از راه دور. خودکار تزریق می‌شود. |
| `TELEGRAM_OWNER` | خالی | آیدی تلگرام کسی که پنل را نصب کرده. |

بقیه تنظیمات — پورت‌ها، IP تمیز، DNS، قوانین مسیریابی و الگوی نام‌گذاری — از داخل
داشبورد ویرایش و در D1 ذخیره می‌شوند.

## 🗺️ مسیرها

| مسیر | کاربرد |
| --- | --- |
| `/{path}/panel` | داشبورد (نیازمند ورود) |
| `/{path}/login` | صفحه ورود |
| `/{path}/sub` | لینک اشتراک عمومی |
| `/{path}/sub?u=NAME` | لینک اشتراک اختصاصی کاربر |
| `/{path}/api/*` | API به فرمت JSON (نیازمند ورود) |
| `/vl` و `/tr` | نقاط اتصال WebSocket |
| هر مسیر دیگر | صفحه استتار |

### فرمت‌های اشتراک

پارامتر `?format=` را اضافه کنید یا بگذارید تابورا از روی User-Agent تشخیص دهد:

</div>

```
?format=base64     v2rayN، v2rayNG، Streisand، Shadowrocket
?format=clash      Clash Meta، Mihomo، Clash Verge، FlClash، Stash
?format=singbox    sing-box، husi، Hiddify، Karing، NekoBox
?format=plain      لیست URI خام، هر خط یکی
```

<div dir="rtl">

اگر لینک اشتراک را در مرورگر باز کنید، به‌جای کانفیگ خام یک صفحه وضعیت شامل میزان
مصرف، تاریخ انقضا و کد QR نمایش داده می‌شود.

## 🧱 ساختار پروژه

</div>

```
src/
├── worker.ts        نقطه ورود و مسیریاب
├── config/          پیش‌فرض‌ها، ثابت‌ها، بارگذار تنظیمات، اعتبارسنج‌ها
├── storage/         لایه D1، اسکیما، کش درون‌ایزوله
├── auth/            نشست JWT و هش رمز عبور
├── protocols/       VLESS، Trojan، رله WebSocket ↔ TCP
├── cores/           سازنده‌های کانفیگ (URI، Clash، Sing-box)
├── users/           مدل مشترک، سهمیه‌ها، حسابداری مصرف
├── handlers/        یک ماژول برای هر مسیر
└── assets/          صفحات پنل، ورود و اشتراک
```

<div dir="rtl">

دستور `npm run build` تمام صفحات را داخل کد قرار می‌دهد، آن‌ها را gzip می‌کند، ورکر
را با esbuild باندل می‌کند و یک فایل مستقل `dist/worker.js` می‌سازد.

</div>

```bash
npm run check    # بررسی تایپ‌ها
npm run build    # ساخت dist/worker.js
npm run dev      # اجرای محلی با wrangler
```

## ⚠️ محدودیت‌ها

چند محدودیت از سمت Cloudflare Workers وجود دارد که هیچ پنلی نمی‌تواند دور بزند:

- **۱۰۰٬۰۰۰ درخواست در روز** روی پلن رایگان — برای چند کاربر کافی است.
- **UDP واقعی پشتیبانی نمی‌شود.** فقط DNS (پورت ۵۳) از طریق DoH تونل می‌شود. تماس
  صوتی و تصویری تلگرام و واتساپ کار نخواهد کرد.
- محدودیت زمان CPU برای هر درخواست.
- کلودفلر ممکن است ورکرهایی که الگوی شناخته‌شده پروکسی دارند را غیرفعال کند.
  تابورا نام پروتکل‌ها را به‌صورت متن ساده در خروجی قرار نمی‌دهد، اما هیچ روش
  مبهم‌سازی برای همیشه کار نمی‌کند.

## 🔒 نکات امنیتی

- رمز پیش‌فرض را فوراً عوض کنید.
- یک `SECURE_PATH` طولانی و تصادفی انتخاب کنید — این اولین خط دفاعی شماست.
- رمزها با نمک (salt) و ۱۰٬۰۰۰ دور SHA-256 هش می‌شوند.
- نشست‌ها پس از ۲۴ ساعت منقضی می‌شوند؛ تغییر رمز، کلید امضا را می‌چرخاند و تمام
  نشست‌های موجود را باطل می‌کند.
- پروکسی استتار، کوکی‌ها و هدرهای CSP سایت مقصد را حذف می‌کند.

بخوانید.
