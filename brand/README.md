# Tabora brand assets

| File | Use |
|---|---|
| `icon.svg` | The mark on its own — favicon, app icon, avatar |

## The mark

A hexagon with a **T** inside, and three filled nodes on alternating vertices.

The shape is doing two jobs. Read one way it is the letter T; read another it
is a network diagram — a hub with links fanning out to peers, which is exactly
what the panel does. The hexagon is the node symbol used throughout
networking, and it also echoes the panel's own rounded, angular UI.

It deliberately avoids the shield-and-padlock cliché that nearly every proxy
panel reaches for, so Tabora is recognisable next to them rather than blending
in.

## Colours

```
#38bdf8  →  #6366f1     (the panel's accent gradient, 135°)
```

The gradient is the only fill. There is no hardcoded background colour, so the
mark sits correctly on light and dark surfaces without a second variant.

## Rules

- Keep clear space of at least half the mark's width on every side.
- Do not recolour it to a flat single colour; the gradient is the identity.
- Minimum size 16px — verified legible at that size.
- Do not add a drop shadow or outer glow.
